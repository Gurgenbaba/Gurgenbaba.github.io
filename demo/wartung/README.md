# ABBES Wartungsprotokoll – Konzeptdemo

Unverbindliche, responsive Frontend-Demo für ein digitales Wartungsprotokoll in der Fördertechnik.

**Wichtig:** Neutrale, unverbindliche Konzeptdemo mit ausschließlich fiktiven Beispieldaten. Keine kundenspezifische Umsetzung.\n\n## Enthalten
- Auftrag, Kunde, Standort und Anlage
- Wartungscheckliste mit OK / Mangel / N/A
- Mängelerfassung inkl. Foto
- Touch-/Maus-Unterschrift
- fertige Protokollansicht mit PDF/Druck
- lokale Browser-Speicherung
- PWA/Offline-Grundlage
- keine externe Bibliothek oder CDN

## Produktion
Die gleiche UI kann später an eine firmeneigene REST-API, PostgreSQL und Dateiablage angebunden und als Docker-Stack in bestehender Infrastruktur betrieben werden.
